# GitHub 与 NAS 的边界

## 核心层

以下内容与部署平台无关：

```text
backend/capture.py
frontend/
data/
scripts/build_site.py
```

## GitHub 专属层

只有：

```text
.github/workflows/
```

负责：

- 定时
- CI 环境
- 自动 commit
- GitHub Pages deploy

## NAS 专属层

以后可增加：

```text
deploy/nas/
├─ nginx.conf
├─ docker-compose.yml
└─ cron
```

不需要修改 `backend/capture.py` 或前端数据格式。

因此 GitHub Pages 是当前的托管方式，不是项目架构本身。
